# Missão Aquário Digital

## Descrição do Ecossistema (Camadas do Ambiente)
O fluxo de trabalho deste repositório é baseado em ramificações (branches) que representam as seguintes camadas:

* **develop**: Ambiente de desenvolvimento. É onde as novas funcionalidades (como o módulo de controle de qualidade da água) são integradas e testadas primeiro.
* **stage**: Ambiente de homologação/teste. Serve como uma réplica do ambiente final para validações de qualidade antes do lançamento oficial.
* **main**: Ambiente de produção. Contém o código mais estável, certificado e pronto para o usuário final.
